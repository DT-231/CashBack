# T-014 — Dán link Shopee → nhận link của tôi

Owner: Codex · Module duy nhất được đụng: `links` · Phụ thuộc: T-004, T-005, T-010 (đã có trên `main`).

## Mục tiêu
Thành viên đã đăng nhập dán một link sản phẩm Shopee và nhận lại `go_url` (link qua web, ghi click, làm ở T-015) và `direct_url` (link affiliate trực tiếp, dự phòng). Gọi lại với cùng sản phẩm thì tái dùng link cũ.

## Endpoint (thêm vào module `links`, tiền tố `/api/v1`)
1. `POST /api/v1/links` body `{"url": "..."}` → 200
   ```json
   {"code": "q8w2e1xk", "go_url": "https://<PUBLIC_BASE>/go/q8w2e1xk",
    "direct_url": "https://shopee.vn/universal-link/product/<shop>/<item>?utm_source=an_...&utm_content=1l-...",
    "product": {"shop_id": 1, "item_id": 2, "name": null}}
   ```
   - Bắt buộc đăng nhập: dùng dependency `current_user` của `app.modules.auth.api` (đã có, trả `UserOut` có `.id`). Thiếu/sai token → 401 theo định dạng lỗi chung.
   - `go_url` = `{settings.public_base}/go/{code}`; `public_base` rỗng thì `go_url` = `null`.
   - `direct_url`: dùng `make_link`/`link_for_item` hiện có với `sub_id` = `app.core.subid.encode("l", user_id, link_id, secret)` (mức link, chưa có click). Secret lấy từ `settings.subid_secret`; thiếu hoặc ngắn → trả 503 `not_configured` (xem cách `ai_posts` xử lý). Không tự ghép chuỗi sub_id.
2. `GET /api/v1/me/links` → danh sách link của chính user: `code`, `go_url`, `product`, `created_at`, `clicks` (số dòng `clicks` có `link_id` đó, hiện luôn là 0 nếu chưa có). Mới nhất trước, `limit` 1–100 (mặc định 50), `offset` ≥ 0.

## Quy tắc nghiệp vụ
- Chuẩn hóa bằng `parse_product_url` hiện có (dạng `/product/{shop}/{item}` và `...-i.{shop}.{item}`).
- Chỉ nhận host `shopee.vn` và `www.shopee.vn` (https hoặc http). Host khác (kể cả `shopee.vn.evil.com`, `s.shopee.vn`, `shope.ee`, userinfo như `https://shopee.vn@evil.com/...`) → 400, `code = "invalid_input"` hoặc lỗi riêng của module. **Link rút gọn `s.shopee.vn` chưa hỗ trợ trong task này**: trả 400 với thông báo "chưa hỗ trợ link rút gọn" (cần gọi Shopee, sẽ làm ở task khác trong `integrations/shopee`).
- Không có `shop_id/item_id` → 400. `url` dài quá 2000 ký tự → 422.
- Sản phẩm lưu vào `products(shop_id, item_id)` (UNIQUE cặp), `name` để NULL, **không gọi Shopee**. Dùng `INSERT ... ON CONFLICT DO NOTHING` rồi SELECT, an toàn khi hai request cùng lúc.
- Một user + một sản phẩm = một dòng `links` (UNIQUE(user_id, product_id) đã có). Dán lại → trả đúng `code` cũ, **không đổi gì**.
- `code`: 8 ký tự `[0-9a-z]` sinh bằng `secrets`; trùng (UNIQUE) thì thử lại tối đa 5 lần.
- Không bao giờ nhận `user_id` từ body; luôn lấy từ token.

## Acceptance criteria
- Given user đã đăng nhập When POST link `https://shopee.vn/Ten-SP-i.5501.100001?sp_atk=abc` Then 200, `product` = {5501, 100001}, `direct_url` có `utm_source=an_<aff_id>` và `utm_content` giải mã được bằng `app.core.subid.decode` thành `type=l`, `owner=user_id`, `ref=link_id`.
- Given cùng user When POST lại cùng sản phẩm (kể cả URL khác dạng) Then cùng `code`, không tạo dòng mới.
- Given hai user khác nhau cùng sản phẩm Then hai `code` khác nhau.
- Given host `https://evil.com/product/1/2`, `https://shopee.vn.evil.com/product/1/2`, `https://shopee.vn@evil.com/product/1/2`, `https://s.shopee.vn/abc` Then 400.
- Given không có/sai token Then 401 (`error.code = unauthorized`).
- Given `GET /me/links` Then chỉ thấy link của chính mình; user B không thấy link của A.
- Given `public_base` rỗng Then `go_url` = null; có `public_base=https://x.test` Then `go_url` = `https://x.test/go/<code>`.
- Lỗi luôn theo định dạng `{"error":{"code","message","request_id"}}`; không có SQL trong `api.py`/`service.py`; không `os.environ`.
